运行说明

启动方式
启动：双击 SqlController.exe（或运行 dotnet run --project SqlController），托盘里点「启动服务」，然后打开 http://127.0.0.1:5288。
重建数据库：在 sql-quiz 目录执行 python make_db.py，把生成的 wms.db 复制到 SqlPlayground/；或在控制器里点「重新编译并重启」。
安全：SQLite 以 mode=ro 打开；MySQL/SQL Server 建议只读账号。后端再叠加只读语句白名单、单条语句校验、5 秒超时和 500 行上限。
图表规则：第一列作为分类轴，数值列作为指标；日期/时间列自动识别为折线图，单数值列用柱状图，多数值列分组柱状。
