方言与判分说明

使用须知
1. 为什么是 SQLite？ 浏览器里能离线运行的只有嵌入式引擎，所以本题库用 SQLite 方言。你工作里用的 MySQL 语法（如 DATE_SUB(CURDATE(), INTERVAL 29 DAY)）在 SQLite 里对应 date('now','-29 days')；WMS 题目里已给出 MySQL 对照写法。
2. 结果集比对规则： 每个单元格转字符串比较（NULL 视为空串），不比较列名；默认把行排序后比较（集合相等），标注「严格比较」的题目按返回顺序逐行比。多行语句取最后一个结果集。
3. 样例数据： world 为常见的国家数据，nobel 为 2000–2015 诺奖记录，emp/dept 为经典员工部门表，两张 WMS 表由脚本生成最近 40 天数据（字段已简化，仅保留出题需要的列）。
4. 判分是「自比对」： 你的 SQL 与标准答案在同一份数据上执行后比对结果，因此即使跨天导致「最近 30 天」窗口变化，两边仍然一致。
